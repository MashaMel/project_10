Двухосная система ориентации солнечной панели

Автор: Мелкумова Мария 10В

Цель проекта:

Создание действующего прототипа автономной системы слежения за солнцем с двумя степенями свободы, который обеспечивает максимальный прирост выработки энергии по сравнению со статичным положением.

Задачи проекта:

  • Создание действующего прототипа автономной системы слежения за солнцем с двумя степенями свободы, который за счет использования датчиков освещенности (LDR) и алгоритмов на MicroPython динамически изменяет положение панели, обеспечивая максимальный прирост выработки энергии по сравнению со статичным положением.
  • Теоретическая часть (Исследование физики процесса)
  • Проектирование и сборка электроники
  • Проектирование механики
  • Разработка программного обеспечения
  • Экспериментальная часть
